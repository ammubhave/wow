Every puzzle has a shared whiteboard: a drawing canvas the whole team can sketch on together. Open it from the **Whiteboard** tab on the [puzzle page](/docs/guides/puzzle-page), next to the sheet.

The whiteboard is built on [Excalidraw](https://excalidraw.com), so if you've used that, you already know the tools: shapes, arrows, lines, freehand drawing, text and images.

## What it's for

Use the whiteboard when a spreadsheet gets in the way:

- Sketching a logic puzzle's grid, a map or a family tree.
- Drawing connections between items with arrows.
- Working out a shape puzzle, a path, or a picture that the answer letters spell.
- Pasting in a screenshot of the puzzle and marking it up.
- Scribbling while you explain an idea on a [voice call](/docs/guides/voice).

Each puzzle has its own whiteboard, whether it uses the built-in spreadsheet or a Google Sheet. It only loads the first time you open its tab, so it doesn't slow the puzzle page down if you never use it.

## Live collaboration

Everyone with the whiteboard open sees each other's edits as they happen, and each person's pointer moves across the canvas with their name.

- **Undo is yours**: <Kbd>⌘ Z</Kbd> (<Kbd>Ctrl Z</Kbd> on Windows) undoes your own changes only. A teammate's edits never end up in your undo history, so you can't accidentally erase their work.
- **Offline**: if you lose your connection, keep drawing. Your changes are sent when you reconnect, and anything your teammates did in the meantime is merged in.
- **Theme**: the whiteboard follows WOW's light or dark theme, which you set from the account menu.

## The menu

The menu button at the top left of the canvas has a few extras: export the drawing as an image, change the canvas background, clear the canvas, and Excalidraw's help (which lists its keyboard shortcuts).

<Callout type="warning">Clearing the canvas clears it for everyone on the puzzle.</Callout>

## Tips

### Drawing grids

For a regular grid (a logic grid, a word search), draw one square with the rectangle tool, then select it and duplicate it with <Kbd>⌘ D</Kbd> (<Kbd>Ctrl D</Kbd>). Duplicate rows the same way. If you need to type into the cells, the [built-in spreadsheet's crossword grid](/docs/guides/spreadsheet#crossword-grids) is often quicker.

### Pasting images

Copy an image (or a screenshot) and paste it with <Kbd>⌘ V</Kbd> (<Kbd>Ctrl V</Kbd>), or use the image tool in the toolbar. Images are shared with the team like any other element, so everyone sees the same picture to mark up. Images can be up to 5 MB.

### Keep it tidy

A whiteboard everyone draws on fills up fast. Group related things together, add a text label to each area ("Grid A", "Ideas for extraction"), and say in the puzzle's chat what you've put where.
