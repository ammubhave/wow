WOW keeps its shortcuts few, so they're easy to remember. On a Mac, use <Kbd>⌘</Kbd> (Command); on Windows and Linux, use <Kbd>Ctrl</Kbd> instead. Shortcuts that type a character, like <Kbd>/</Kbd>, only work when you're not already typing in a box.

## Workspace

| Keys                                             | What it does                                                                        |
| ------------------------------------------------ | ----------------------------------------------------------------------------------- |
| <Kbd>⌘ K</Kbd> / <Kbd>Ctrl K</Kbd>               | Open or close the command palette: jump to any puzzle, page, team link or docs page |
| <Kbd>↑</Kbd> <Kbd>↓</Kbd>, then <Kbd>Enter</Kbd> | Pick a result in the command palette                                                |
| <Kbd>Esc</Kbd>                                   | Close the command palette                                                           |

The command palette has no button: it's keyboard only. On a phone, use the menu button instead.

## Blackboard

| Keys             | What it does                                         |
| ---------------- | ---------------------------------------------------- |
| <Kbd>/</Kbd>     | Focus **Search puzzles…**                            |
| <Kbd>Enter</Kbd> | Save the answer you're typing in a **Solution** cell |
| <Kbd>Esc</Kbd>   | Cancel the answer you're typing                      |

## Answers & notes

| Keys                                       | Where                           | What it does                              |
| ------------------------------------------ | ------------------------------- | ----------------------------------------- |
| <Kbd>Enter</Kbd>                           | **Answer** box on a puzzle page | Save the answer (clicking away saves too) |
| <Kbd>Enter</Kbd>                           | **Queue a guess to call in**    | Queue the guess                           |
| <Kbd>⌘ Enter</Kbd> / <Kbd>Ctrl Enter</Kbd> | Notes (blackboard or puzzle)    | Save the notes                            |
| <Kbd>Esc</Kbd>                             | Notes                           | Cancel editing                            |

## Chat

| Keys                               | What it does                                                 |
| ---------------------------------- | ------------------------------------------------------------ |
| <Kbd>Enter</Kbd>                   | Send the message                                             |
| <Kbd>Shift Enter</Kbd>             | Start a new line                                             |
| <Kbd>Enter</Kbd> or <Kbd>Tab</Kbd> | After typing `@` and part of a name, pick the top suggestion |
| <Kbd>Enter</Kbd>                   | Save a message you're editing                                |
| <Kbd>Esc</Kbd>                     | Cancel editing a message                                     |

## Docs

| Keys                               | Where                                        | What it does    |
| ---------------------------------- | -------------------------------------------- | --------------- |
| <Kbd>/</Kbd>                       | Docs (public, or a workspace's **Help** tab) | Search the docs |
| <Kbd>⌘ K</Kbd> / <Kbd>Ctrl K</Kbd> | Public docs                                  | Search the docs |

Inside a workspace, <Kbd>⌘ K</Kbd> opens the workspace's command palette instead, which also lists every docs page.

## Puzzle Exchange

| Keys         | What it does                        |
| ------------ | ----------------------------------- |
| <Kbd>/</Kbd> | Search puzzles on the Exchange page |

## Sheets and whiteboard

The built-in spreadsheet and the whiteboard keep their own usual keys (copy, paste, undo and so on). Google Sheets, when your team uses Google Drive, works with Google's shortcuts.
