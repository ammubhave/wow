Eggö is WOW's chat bot. It answers a couple of commands with a nudge when you're stuck on a puzzle.

## Commands

| Command  | What you get                                                 |
| -------- | ------------------------------------------------------------ |
| `!help`  | The list of commands                                         |
| `!stuck` | A random solving hint, with a **🧇 Roll** button for another |

Start your message with the command: `!stuck` and `!stuck on the grid` both work, but "I'm !stuck" is just a message.

## Where it works

Eggö works in **any chat** in WOW: the team chat on the blackboard and every puzzle's chat. There's nothing to set up.

Your message is posted as usual, Eggö reacts to it, and its reply appears just below from "Eggö" (with a 🧇 avatar), so everyone in the chat sees it.

## Using !stuck

<Steps>

1. In a puzzle's chat, send `!stuck`.
2. Eggö replies "Try this!" with a numbered hint.
3. Not helpful? Click **🧇 Roll** for a different one. Rolling only changes what you see, so each teammate can roll their own.

</Steps>

There are 37 hints, drawn from common puzzle hunt advice. A few examples:

- "Read down the first letters."
- "Index numbers into words."
- "Take a break! Do something else."

<Callout type="tip">
  The hints are prompts, not answers. They're most useful read aloud to the group, as a reason to
  try something you haven't yet.
</Callout>
